# 软著可用功能模块说明

- 蜜蜂行为虚拟仿真系统

## 2. 功能模块划分

### 2.1 蜜蜂飞行控制模块
**对应文件**：`Assets/Scripts/beeljk/BeeSimulation.cs`  
**功能说明**：
- 实现蜜蜂对象的基础飞行运动控制。
- 支持前进、转向、升降、加速、姿态平滑等逻辑。
- 支持自动目标飞行与玩家控制两种模式。

**软著描述建议**：
- 一种面向虚拟场景的昆虫飞行控制模块。
- 一种支持姿态联动与速度限制的飞行行为模拟模块。

---

### 2.2 目标搜索与悬停采集模块
**对应文件**：`Assets/Scripts/beeljk/BeeTargetController.cs`  
**功能说明**：
- 负责目标列表管理、最近目标搜索、到达减速、悬停停留。
- 支持玩家采集点吸附与微扰动悬停效果。
- 支持多目标自主访问。

**本次新增点**：
- 新增**目标循环访问**能力：访问完一轮目标后自动进入下一轮。
- 新增**稳定路线回放**能力：记录上一轮访问顺序，并在后续轮次优先复用。

**软著描述建议**：
- 一种面向花源目标的自主搜索与停留控制模块。
- 一种支持循环访问与路径记忆的目标调度模块。

---

### 2.3 环境感知与避障控制模块
**对应文件**：`Assets/Scripts/beeljk/BeeSimulation.cs`  
**功能说明**：
- 基于射线检测实现前向障碍规避。
- 支持地面安全高度规避。
- 支持扰动噪声叠加，增强路径自然度。

**软著描述建议**：
- 一种基于环境感知的自主避障模块。
- 一种支持地面规避与扰动模拟的飞行安全控制模块。

---

### 2.4 飞行轨迹与调试可视化模块
**对应文件**：
- `Assets/Scripts/beeljk/BeeSimulationManager.cs`
- `Assets/Scripts/beeljk/VisualizationManager.cs`

**功能说明**：

- 开关调试射线、受力显示、噪声显示等可视化信息。
- 支持演示过程中的显示控制。

**软著描述建议**：
- 一种飞行轨迹记录与展示模块。
- 一种行为调试信息可视化模块。

---

### 2.5 演示辅助交互模块

## 4. 场景绑定/使用方法

1. 打开 `Demo.unity` 场景。
2. 选中蜜蜂对象，确认其挂载 `BeeSimulation` 与 `BeeTargetController`。
3. 在 `BeeTargetController.targets` 中拖入多个花朵目标。
4. 勾选：
   - `enableHover`
   - `enableTargetCycleLoop`
   - `enableStableRouteReplay`
5. 运行场景后观察：
   - 蜜蜂依次访问目标
   - 一轮结束后自动继续下一轮
   - 后续轮次优先复用已形成的访问顺序
